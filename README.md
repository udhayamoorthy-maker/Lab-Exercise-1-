# FUNDAMENTALS OF UI AND UX
## User Interface (UI)

User Interface refers to the visual and interactive elements through which users interact with a digital product or application. It includes buttons, icons, colors, typography, images, menus, search bars, and layouts.

## User Experience (UX)

User Experience refers to the overall experience and satisfaction of a user while interacting with a digital product or application. UX focuses on usability, accessibility, navigation, efficiency, and user satisfaction.

## RELATIONSHIP BETWEEN UI AND UX

UI and UX are closely connected in the design process. UX focuses on how the application works and how easily users can complete their tasks, whereas UI focuses on how the application looks and how users interact with its visual elements.

In Meesho and Myntra, UX determines the user flow from searching for a product to purchasing it. UI represents this flow through search bars, product cards, buttons, icons, images, menus, and checkout screens.

User Needs → UX Design → UI Design → Interaction → User Satisfaction
